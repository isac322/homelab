### CASE-20260926-issue-only-explorer-owner
- 상태: applied
- 출처: omp session 01a0dbf0 msg a149b6b1
- 상황: 사용자 소유 공개 저장소 제품이 배포된 실사용 공유 클러스터의 live QA를 맡기면서 발견한 문제의 처리 범위와 에이전트 역할 분담을 지정했다.
- 대상: 배포 환경 live QA(탐색 → 이슈 등록) / 사용자 소유 공개 저장소(Kubernetes operator) / GitHub 이슈, 임시 namespace 리소스 / 중간(다른 워크로드와 공유하는 실사용 클러스터)
- 적용 조건: 사용자가 배포 환경 live QA를 맡기는 모든 경우. 기존 리소스 R만과 임시 격리 단위 사용은 인터뷰에서 다른 범위를 승인받지 않았을 때의 기본
- 사용자 기대: 문제는 고치지 않고 이슈 등록까지만 한다. 메인은 탐색만 하고, finding마다 새 subagent가 조사부터 이슈 생성까지 맡는다. 기존 리소스는 R만, 상태 처리 검사는 임시 namespace에서 하고 끝나면 제거한다.
- 실제 행동: 사전 규칙 없음(사용자 지시로 규칙 수립).
- 원인 분류: missing / 규칙: LQA-01, LQA-10, LQA-15, LQA-27, LQA-33, LQA-38
- 변경: 없음 → 해당 규칙 신설
- 일반화: global
- 재발 확인 기준: 메인이 finding을 직접 파고들거나 코드를 고치지 않고, 이슈와 정리 증명으로 끝난다.
