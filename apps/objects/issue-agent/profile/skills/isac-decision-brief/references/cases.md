### CASE-20260916-conditional-go
- 상태: applied
- 출처: omp session 01a095f6 msg ASK@2026-09-16T15:18; msg efc2065b
- 상황: 사용자가 "브랜치 갱신 후 다시 확인해서 범위 안 변경만 보이면 적용하고 끝까지, 아니면 멈춤"이라는 조건부 지시를 줬다(예: flareway IaC 정리).
- 대상: IaC 정리 적용 / 공유 인프라 저장소 / Terraform plan·apply / 높음
- 적용 조건: 사용자가 참·거짓으로 평가 가능한 조건과 함께 진행을 지시했을 때
- 사용자 기대: 조건이 참이면 다시 묻지 않고 끝까지 진행한다. 거짓이면 멈추고 보고한다.
- 실제 행동: 범위 밖 변경 1건 때문에 조건이 거짓이어서 멈추고 보고했다(정상 동작). 사용자는 그 항목이 이 프로젝트에서 알려진 provider 노이즈라며 적용하고 계속하라고 지시했다.
- 원인 분류: 교정 아님(정상 동작, 지시 사례) / 규칙: DBR-13, DBR-21
- 변경: 신규 → 조건 평가 후 참이면 끝까지, 거짓이면 멈춤과 보고. 보고에 실제 변경과 알려진 노이즈를 구분해 적는다(DBR-21, 기본값).
- 일반화: global(지시 해석). 특정 리소스가 알려진 노이즈라는 사실은 memory.
- 재발 확인 기준: 조건이 참이면 평가 결과 한 줄 뒤에 추가 질문 없이 진행한다. 거짓이면 멈춤 보고에 조건을 깬 항목이 실제 변경인지 노이즈인지 적혀 있다.
