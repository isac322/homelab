# Style — 공개 텍스트 기본값

`isac-github-publishing`의 GHP-05·GHP-06 세부 기본값이다(바꿀 수 있는 기본값; 각 호출 스킬의 템플릿이 더 구체적이면 그것이 우선한다). 문체 자체는 `writing-clearly-and-concisely`, `humanizer`, `comment-writer`가 소유한다.

## 구조 기본값

- 맨 앞 한 단락에 **판정·결론**을 둔다(독자가 본문을 다 읽지 않아도 결론을 안다).
- 이어서 **근거 단락**: 무엇을 어느 버전·commit·환경에서 실행했고 무엇이 관찰됐는지(정상 대조군 포함).
- 그 뒤는 호출 스킬의 템플릿을 따른다(분석 절, 상태 갱신 등).
- 닫기·상태 갱신 류의 짧은 코멘트는 상세 근거를 반복하지 않고 이전 댓글·PR을 참조한다.

## 증거 표기 기본값

| 상태 | 표기 |
|---|---|
| 실행하고 관찰했다 | 실행 명령·버전·환경과 함께 결과를 그대로 적는다 |
| 아직 실행 전 | “pending”으로 표시. 공개하지 않는다 |
| 추론이고 미측정 | `[INFERENCE]` |
| 확인하지 않았다 | 확인하지 않았다고 명시한다. 확인 영역 밖의 주장은 만들지 않는다 |

- 다른 저장소·외부 작성자가 읽을 수 있으므로 어조는 일방적 단정 대신 비례적인 권고형을 기본으로 한다(예: "I recommend …"). 단, 판정 자체는 흐리지 않는다.

- 템플릿·본문에 em dash(—)·en dash(–)를 쓰지 않는다(규칙은 `humanizer` 소유; 초안 검토 시 확인한다).
