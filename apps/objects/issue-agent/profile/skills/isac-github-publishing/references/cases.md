### CASE-20260917-pr-english-chat-korean
- 상태: applied
- 출처: omp session 01a095f6 msg 79d2095e (공개 프로젝트 flareway)
- 상황: 큰 기능 PR 생성을 지시하며 언어와 길이를 나눠 지정했다.
- 대상: 큰 기능 PR 생성 / 사용자 소유 공개 저장소 / PR 본문 + 채팅 보고 / 낮음
- 적용 조건: 언어 분리(GitHub 영어, 채팅 한국어)는 모든 게시에 적용. "PR 본문은 길어도 된다"는 PR 본문 전반의 허용. "전반 구조·방향을 적는다"는 큰 구조 변경 PR에만 적용(태그 없는 GHP-05).
- 사용자 기대: PR 본문은 영어로 쓰고 길어도 되며, 사용자 보고(채팅)는 한국어로 최대한 짧고 간결하게 글쓰기 스킬을 적용한다.
- 실제 행동: PR 본문은 영어로 작성하고 채팅 보고는 한국어로 분리했다.
- 원인 분류: missing / 규칙: GHP-02
- 변경: 언어 분리(GitHub=영어, 채팅=한국어)와 “PR 본문은 길어도 됨”을 GHP-02 [U]에 포함. “전반 구조·방향을 적는다”는 이 요청(큰 구조 변경 PR)에 한정된 것이라 태그 없는 GHP-05로 둠.
- 일반화: global (언어 분리). PR 본문 내용은 해당 요청 범위.
- 재발 확인 기준: 채팅 보고가 영어이거나 PR 본문이 한국어이면 재발.

### CASE-20260926-skip-or-augment
- 상태: applied
- 출처: omp session 01a0dbf0 msg ae572f94 (공개 프로젝트 flareway); omp session 01a0d288 msg 59de466d (공개 프로젝트 kwin-mcp)
- 상황: (1) 같은 세션에서 에이전트가 만든 이슈에 수정 아이디어를 추가하자고 제안하자, 사용자는 이미 반영됐는지 묻고 스킵 또는 보강을 지시했다. (2) 이슈 없는 PR들을 처리하라며 이슈를 새로 만들지 말고 해당 PR에 댓글이나 코드 push로 처리하라고 했다.
- 대상: 이슈 기록·PR 정리 / 사용자 소유 공개 저장소 / 기존 이슈·PR(에이전트가 만든 이슈 포함) / 낮음
- 적용 조건: 게시하려는 내용과 관련된 기존 이슈·PR이 이미 있을 때만. 관련 대상이 없으면 새로 만든다.
- 사용자 기대: 관련 이슈·PR이 이미 있으면, 반영된 내용은 스킵하고 아니면 그 이슈·PR을 보강한다. 새 이슈는 만들지 않는다.
- 실제 행동: 이미 반영된 항목은 건너뛰고 기존 이슈를 보강했다.
- 원인 분류: missing / 규칙: GHP-10
- 변경: “관련 기존 이슈·PR이 있을 때: 반영됨 → 스킵, 아니면 새 이슈 없이 보강”을 [U]로 명문화(보강 방식은 기본값 GHP-11).
- 일반화: global (관련 대상이 이미 있는 경우로 한정)
- 재발 확인 기준: 관련 이슈·PR이 있는데 같은 내용을 새 이슈로 게시하면 재발.

### CASE-20260918-close-not-delete
- 상태: applied
- 출처: omp session 01a0ae59 msg 58d012db; omp session 01a0b303 msg fb83388a; omp session 01a0b303 msg 9d9980a8; omp session 01a0ae59 msg 97ed0fbf (공개 프로젝트 flareway)
- 상황: 이슈 #11과 PR #8(다른 PR로 이미 대체됨)을 누가 만들었는지 사용자가 두 번 질문했고, 이어 PR을 “제거”하라고 지시했다. 출처 질문은 교정이 아니었다.
- 대상: 이전 세션 산출물 정리 / 사용자 소유 공개 저장소 / 에이전트가 만든 PR(다른 PR로 커밋이 흡수됨) / 중간(비가역 삭제 회피)
- 적용 조건: 에이전트가 만든 이슈·PR에 대한 "제거" 지시일 때만. 브랜치·댓글, 사람이 만든 산출물에는 적용하지 않는다. 산출물 추적은 이 케이스의 [U]가 아니다(GHP-11 기본값).
- 사용자 기대: 에이전트가 만든 이슈·PR을 “제거”하라는 지시는 삭제가 아니라 close다.
- 실제 행동: 커밋이 다른 PR로 이미 들어간 PR을 close로 처리했다.
- 원인 분류: missing / 규칙: GHP-12
- 변경: close 의미만 [U](GHP-12). 산출물 추적은 태그 없는 기본값(GHP-11).
- 일반화: global (에이전트가 만든 이슈·PR 범위)
- 재발 확인 기준: “제거해”를 삭제로 처리하면 재발.
